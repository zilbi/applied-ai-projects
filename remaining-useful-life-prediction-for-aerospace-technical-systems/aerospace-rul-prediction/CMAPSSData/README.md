# NASA C-MAPSS FD001 Data

This directory contains only the FD001 files used by the final notebook:

- `train_FD001.txt` — complete run-to-failure training trajectories
- `test_FD001.txt` — truncated test trajectories
- `RUL_FD001.txt` — official remaining-life labels for the test engines
- `readme.txt` — original dataset description and column information

FD001 simulates one operating condition and one fault mode. The data was copied
from the project team's source repository without modification.
